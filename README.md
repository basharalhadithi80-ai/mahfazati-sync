# سيرفر مزامنة محفظتي

سيرفر الحسابات والمزامنة الخاص بتطبيق المحفظة «محفظتي» — النسخة الأولى (2026-11-16).
بايثون فقط، بدون أي مكتبات خارجية: يشتغل على أي جهاز فيه Python 3.8+.

## شنو يسوي

حساب بإيميل وكلمة سر، ونسخة مشفرة من بطاقات المستخدم تنحفظ بالسيرفر،
حتى وين ما يسجل دخول وينزّل التطبيق تطلع نفس البطاقات:

- المستخدم يسجل بإيميل وكلمة سر (كلمة السر تنحفظ scrypt مشفرة، مو نص).
- التطبيق يشفر نسخة البطاقات على الموبايل (AES/GCM بمفتاح مشتق من كلمة سر
  الحساب PBKDF2-HMAC-SHA256 بـ100,000 تكرار) ويرفعها للسيرفر.
- السيرفر يخزن الـblob والـsalt كما هما — **ما يكدر يفك تشفيرهما**،
  وما يشوف أرقام البطاقات ولا كلمة السر ولا مفتاح التشفير أبداً.
- إذا نسي المستخدم كلمة سر الحساب، نسخة السيرفر ما تكدر تسترجعها —
  البطاقات تبقى على الموبايل، ويرجع يرفعها بحساب جديد.

## التشغيل

```bash
PORT=8000 python3 server.py
```

- أول تشغيل ينشئ `wallet.db` بجانب السكربت.
- السجلات تحمل method/path/status فقط — بدون كلمات سر أو توكنات أو blobs.

## الواجهة

- `GET /health` → `{"ok": true}`
- `GET /` → صفحة حالة بسيطة
- `POST /api/register` `{email, password}` → `{token}` — إيميل صحيح + كلمة سر 8 أحرف فأكثر؛ 409 إذا الإيميل مسجل
- `POST /api/login` `{email, password}` → `{token}` — بعد 5 محاولات فاشلة لنفس الإيميل خلال 5 دقائق يرجع 429
- `POST /api/vault` `{token, blob, salt, updated}` → `{ok: true}` — حفظ/تحديث نسخة المستخدم
- `GET /api/vault?token=…` → `{blob, salt, updated}` — 404 إذا ما توجد نسخة بعد
- `POST /api/password` `{token, old_password, new_password}` → `{ok: true}` — تغيير كلمة السر (التطبيق يعيد تشفير النسخة ويرفعها بعدها)

التوكن: 32 بايت عشوائي، صالح 30 يوماً ويتجدد تلقائياً مع كل استخدام موثّق.

## النشر على Render (الباقة المجانية)

1. أنشئ مستودع GitHub جديد وارفع ملفات هذا المجلد
   (`server.py`، `render.yaml`، `requirements.txt`، `README.md`).
2. في Render: New ← Web Service ← اختر المستودع.
   ملف `render.yaml` يضبط كل شيء تلقائياً (بايثون، باقة مجانية،
   أمر التشغيل `python3 server.py`).
3. عنوان الخدمة المتوقع: `https://mahfazati-sync.onrender.com`
   (التطبيق يحمل هذا العنوان كثابت `SYNC_BASE_URL`).

## تحذير — الباقة المجانية

الباقة المجانية تنام بعد ~15 دقيقة خمول، ونظام ملفاتها مؤقت —
قاعدة بيانات الصالون انمسحت بهالطريقة بتاريخ 2026-11-04.
الموبايل يبقى النسخة الأساسية من البطاقات؛ نسخة السيرفر تُرفع من
الموبايل بأول مزامنة بعدها، فالمسح قابل للاسترجاع ما دام الموبايل
محتفظ بالبطاقات. والتطبيق يقدم أيضاً تصدير/استيراد نسخة احتياطية
مشفرة يدوياً كشبكة أمان.
